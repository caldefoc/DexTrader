Production install requires cloning into `/srv/dextrader`, copying `.env.example` to `.env` and setting `DEMO_MODE=1` / `NEXT_PUBLIC_DEMO_MODE=1`, then `docker compose up -d --build`; after that, append `deploy/Caddyfile.snippet` to `/etc/caddy/Caddyfile`, validate with `sudo caddy validate`, and reload via `systemctl reload caddy`. Updating means `cd /srv/dextrader && git pull && docker compose up -d --build`.
