Two sibling services — `backend/` (FastAPI + Uvicorn agent loop) and `frontend/` (Next.js App Router wallet-driven DEX assistant) — share no code; they communicate over HTTP on localhost using the contract defined by the backend's REST endpoints (`/market`, `/portfolio`, `/agents`, `/signals`, `/news`). The root `.env` is the single configuration surface: each child reads its own subset of variable names (`DEMO_MODE` / `NEXT_PUBLIC_DEMO_MODE`, `BASE_RPC_URL`, `DEXTRADER_STATE_DIR`, API keys). `docker-compose.yml` is the production-ish demo entry point (backend first, frontend depending on it, both bound to loopback behind Caddy), while `start_dev.bat` and `start-all.ps1` launch both dev servers from one Windows Terminal session. `deploy/` holds the Caddy reverse-proxy snippet and GitHub Actions CI that builds/lints both children; `agent_guidelines.txt` is the design brief the backend agents implement.
